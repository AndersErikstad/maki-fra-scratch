# Et lite nevralt nettverk fra scratch

Her er nettverket fra MAKI-laben i python, med to innganger i input-laget, ett skjult lag med åtte nevroner og ett output-nevron. Alt ligger i `nettverk.py`, og du trenger kun python for å kjøre.

```sh
python3 nettverk.py
python3 nettverk.py sirkel
```

Du kan også prøve `and` og `or`. Nettverket bruker tanh, sigmoid og backprop, og skriver ut loss og noen prediksjoner etter trening:)

Prøv å endre antall nevroner, læringsraten eller dataene og se hva som skjer!
